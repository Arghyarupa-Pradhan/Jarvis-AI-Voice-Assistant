# 🤖 Jarvis – AI Voice Assistant

Jarvis is a Python-based personal AI voice assistant that allows users to interact with their computer using voice commands. It listens to the user's voice, understands commands, processes requests, and responds through voice output.

It uses Speech Recognition for converting speech into text, Pyttsx3 for generating spoken responses, and Ollama for AI-powered conversations.

## 🚀 Features

- 🎤 **Voice Input:** Listens to user commands through a microphone.
- 🗣️ **Voice Response:** Jarvis replies to users verbally using Text-to-Speech.
- 🧠 **AI Conversations:** Uses Ollama to generate intelligent responses.
- 🌐 **Web Automation:** Opens websites and performs browser-related tasks.
- ⚡ **Command Execution:** Processes voice commands and performs supported actions.
- 🔍 **Fuzzy Matching:** Uses fuzzy matching to recognize similar commands.

## 🔄 How Jarvis Works

1. User speaks a command.
2. Jarvis captures the voice through a microphone.
3. Speech Recognition converts the voice into text.
4. Jarvis processes the command.
5. Ollama generates an AI response when needed.
6. Pyttsx3 converts the response into speech.
7. Jarvis speaks the response to the user.
